# ガイド — やりたいことから引く

> **対象読者**: ziggurats で特定のことをしたい人（すでに `zts` が動く状態）。
> **所要時間**: 必要な 1 本だけ読んでください（各 5〜10 分）。

ガイドは**目的別**です。概念から順に読む必要はありません。ただし、まだ 1 度も動かして
いない人は、先に [はじめての ziggurats](../start.md)（10 分）を済ませてください。このページは
「すでに動くものがある人」のための索引です。

## ガイドの読み方

各ガイドの先頭 12 行に、**対象読者・所要時間・前提**が書いてあります。そこを読んで
自分に合わなければ、別のページへ移ってください。全部読む必要はありません。

- コードブロックのうち、`zig check` が付いているものは **CI が実際にコンパイルしています**。
  古い API を書くと CI が赤くなるので、ここに書いてあるコードは今のバージョンで通ります。
- `> [!WARNING]` はデータを失う操作か、無言で失敗する設定です。飛ばさないでください。
- 用語で迷ったら [用語集](../../../glossary.md)、名前で引きたいなら
  [API リファレンスの索引](../../../api/index.html) へ。

## 内部向けの資料を読みたいとき

ziggurats 自体の設計（なぜこの構成なのか、どのマイルストーンで入ったか）は
`docs/architecture/` `docs/decisions/` `docs/tasks/` にあります。**アプリを作るだけなら
読む必要はありません** — 公開サイトでは「内部資料」1 エントリに畳まれています。
