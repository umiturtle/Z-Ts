# チュートリアル

> **対象読者**: 説明より手を動かしたい人。
> **所要時間**: 1 本 10〜20 分。

チュートリアルは**最後まで行くと動くもの**が残るように書いています。途中で分からない言葉が
出てきたら、その場で [用語集](../../../glossary.md) を引いてください（読むのを止める必要は
ありません）。

| チュートリアル | 作るもの | 学ぶこと |
|---|---|---|
| 1. [カウンターを作る](counter.md) | クリックで数が増えるアプリ（デスクトップ / ブラウザ / 静的サイト） | `zts init` → コマンド → 画面 → ビルド |
| 2. [Todo リストを作る](todo.md) | 追加・完了・削除ができる一覧 | 構造体に閉じた状態・失敗の返し方・コマンドのテスト |
| 3. [画面を作る](ui.md) | 読み込み中 / 空 / エラーを出し分ける画面 | 画面の状態・CSS の差し替え・CSP |

## 好きなライブラリで進む

3 本とも **Zig 側は共通**です。フロントエンドだけ、実物の example がコミットされている
9 ライブラリ＋素の JS から選べます。**選んだ 1 本を読めばよく、所要時間は増えません**
（分岐は追加の章ではなく代替の道です）。

[選択ハブ](frameworks.md) には各 example のソース・ビルド方法・公開デモへのリンクもあります。

## 進め方

1. **上から順に進めてください。** 2 は 1 のプロジェクトをそのまま使います（`todo.md` は新しい
   プロジェクトでも構いません）。
2. **写経してください。** コピーでも構いませんが、1 回は手で打つと迷いどころが見えます。
3. **各章の終わりに動かしてください。** 動かないまま先に進むと、原因の切り分けが難しくなります。
4. **`zig check` のブロックは CI がコンパイルしています。** ここに書いてあるコードは
   実際にビルドが通るものだけです（古くなるとチュートリアルが赤くなります）。

## 前提

- `zts` が手元にある（[インストール](../guides/install.md)）
- Zig 0.17 が `PATH` か `ZTS_ZIG` にある
- ターミナルが使える

まだ `zts` を持っていない・1 度も動かしていないなら、先に
[はじめての ziggurats](../start.md)（10 分）を済ませると、この章の 0〜1 を飛ばせます。
