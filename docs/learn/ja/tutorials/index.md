# チュートリアル

> **対象読者**: 説明より手を動かしたい人。
> **所要時間**: 1 本 10〜15 分。

チュートリアルは**最後まで行くと動くもの**が残るように書いています。途中で分からない言葉が
出てきたら、その場で [用語集](../../../glossary.md) を引いてください（読むのを止める必要は
ありません）。

| チュートリアル | 作るもの | 学ぶこと |
|---|---|---|
| [カウンターを作る](counter.md) | クリックで数が増えるアプリ（デスクトップ / ブラウザ / 静的サイト） | `zts init` → コマンド → 画面 → ビルド |

## 進め方

1. **写経してください。** コピーでも構いませんが、1 回は手で打つと迷いどころが見えます。
2. **各章の終わりに動かしてください。** 動かないまま先に進むと、原因の切り分けが難しくなります。
3. **`zig check` のブロックは CI がコンパイルしています。** ここに書いてあるコードは
   実際にビルドが通るものだけです（古くなるとチュートリアルが赤くなります）。

## 前提

- `zts` が手元にある（[インストール](../guides/install.md)）
- Zig 0.17 が `PATH` か `ZTS_ZIG` にある
- ターミナルが使える
