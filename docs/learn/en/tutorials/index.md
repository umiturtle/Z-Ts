# Tutorials

> **Audience**: readers who would rather type than read.
> **Time**: 10–15 minutes per tutorial.

Every tutorial **leaves you with something that runs**. When a term gets in the way, look it up in
the [glossary](../../../glossary.md) — you do not have to stop and read a chapter.

| Tutorial | You build | You learn |
|---|---|---|
| [Build a counter](counter.md) | an app where clicking increments a number (desktop / browser / static) | `zts init` → command → UI → build |

## How to work through one

1. **Type it, do not only read it.** Copying works, but typing once shows you where you hesitate.
2. **Run it at the end of every chapter.** Carrying a broken build forward makes causes hard to
   separate.
3. **`zig check` blocks are compiled by CI.** Every block marked that way builds; a tutorial that
   goes stale turns red.

## Before you start

- `zts` on your machine ([Install](../guides/install.md))
- Zig 0.17 on `PATH` or in `ZTS_ZIG`
- a terminal
