日本語とラテン文字が混ざる画面で、
行間と字面が破綻しないこと。

同梱 ZTS Serif / ZTS Sans / ZTS Mono のみ · letter-spacing 0.38px · line-height 30px

WebView は OS ごとにフォントスタックが異なります。Z-Ts はその差異を吸収するのではなく、 「同じ HTML が同じように組まれる」ことを CI のスクリーンショットで確認します。

かな漢字交じり文では、句読点の詰め（約物半角）と行頭禁則が破綻すると一気に素人っぽく見えます。 ここでは 「、」「。」 を含む段落を 2 段組みにして、禁則処理の効きを見ます。

数字と英単語は font-variant-numeric とカーニングの確認用です: 0123456789 · AVATAR · Typography · kerning · ligature fi fl。

行長は 44 文字前後を上限にし、両端揃えは使いません。素の折返しで比較します。最終行の処理が プラットフォーム間で揃っているかを目視で比較できます。
